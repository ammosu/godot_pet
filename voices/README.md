# 內建聲音

這個資料夾放的是**跟著專案一起散布**的說話聲音：qwen3-tts.cpp 的 speaker
embedding，副檔名 `.emb`，一個 4 KB。首次啟動時會被複製到
`user://qwen3_tts/voices/`，之後就跟使用者自己克隆的聲音混在同一個清單裡，
在「說話」選單中選。

檔名就是選單上的名字。想改名字就改檔名。

目前內建三個。同一個 session、同一句話量到的中位 F0：

| 名字 | 參考音長度 | 中位 F0 |
|---|---|---|
| （預設嗓音） | —— | 296.3 Hz |
| `anna` | 18.6 秒 | 230.8 Hz |
| `lulu` | 16.7 秒 | 275.9 Hz |
| `yu` | 21.5 秒 | 125.7 Hz |

**要比就要在同一次執行裡比。** 預設 temperature 0.9 讓合成是隨機的，同一個嗓音
在不同次執行量到的 F0 可以差 60 Hz 以上 —— 這張表換一次執行整排都會動，能看的
只有彼此的相對關係。而且 F0 只是個粗糙的代理指標：音色不同但基頻相近的兩個聲音
（這裡的 lulu 跟預設嗓音就只差 20 Hz）聽起來完全不一樣。最後還是要用耳朵。

## 怎麼做一個

在寵物裡錄一段話（選單的 `錄一段話`），到「我做的東西」按那個 wav 旁邊的
`當我的聲音`，取個名字。做出來的檔案在
`user://qwen3_tts/voices/<名字>.emb` —— 在 Linux 上是
`~/.local/share/godot/app_userdata/Godot Pet/qwen3_tts/voices/`。
確定要內建的話，把它複製進這個資料夾並 commit。

也可以直接用 CLI 產：

```sh
qwen3-tts-cli -m ./models -r 參考音.wav --save-embedding 名字.emb
```

參考音不需要先處理 —— 函式庫自己會 resample 跟降混，實測 44.1 kHz 立體聲
跟同一段音訊的 24 kHz 單聲道抽出來的 embedding，cosine 相似度 0.999。
但**不能是靜音**：空房間的錄音一樣會抽出 1024 個格式正確的數字，然後寵物
就用一個沒人選過的嗓音講話，所以峰值低於 0.05 會被擋下來。

## 放進來之前想一下

一個 embedding 是從**某個人的聲音**推導出來的，而這個 repo 是公開的。這裡
沿用專案對 pet pack 的同一條線（見 CLAUDE.md）：衍生素材一律進 `user://`，
不隨 repo 散布。會放進這個資料夾的，應該是你自己的聲音、或是你確定可以公開
散布的來源。

不確定的話就別放 —— 留在 `user://qwen3_tts/voices/` 一樣能用，只是換一台
機器要自己複製那個 4 KB 的檔案。
