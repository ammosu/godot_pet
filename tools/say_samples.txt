# 給 tools/hear.sh 用的試聽句。一行一句，# 開頭是註解，[名字] 開一個新組。
#
# 這些句子存在的理由是「這裡沒有人聽得到」——prompts/pronunciation.json 的每
# 一條都得有人聽過才能加，所以需要一份固定的、改完表就能重跑的清單，用來確認
# 修好的還是好的、沒壞的沒被弄壞。
#
#   tools/hear.sh          # 全部重產
#   tools/hear.sh 覺       # 只產這一組
#
# 加句子的原則：寫寵物真的會講的話。這裡不是字典，是回歸測試——一句沒人會聽到
# 的話唸錯了也不必修，而修它的規則反而可能誤傷會聽到的話。

[覺]
# 已經加了規則的，確認還是對的
今天感覺不錯欸，你呢？
我發覺你今天比較安靜。
我察覺你有點累了。
我的直覺說這樣可以。
那只是錯覺啦。
# 不該被動到的：覺得的覺在詞首，睡覺的覺本來就唸 jiào
我覺得這樣就可以了。
你不睡覺喔？
睡一覺起來就好了。
# 還沒聽過的，照「詞尾的覺會錯」推測應該要修，但沒聽過就不加
你有沒有自覺啊？
不知不覺就這個時間了。
我的視覺跟聽覺都很好。

[著]
# 「著」有三個讀音，而寵物三個都會講到，所以整組一起聽——修 zháo 的規則絕對
# 不能誤傷另外兩個。
# 詞尾接動詞的輕聲 zhe，本來就對，加規則之後要確認還是對的
晚安囉，我先去角落躺著。
你已經盯著螢幕好久了，要不要看一下窗外？
我在這裡等著你回來。
# zháo：使用者聽到唸錯的就是這個
我剛剛差點睡著。
你昨天很早就睡著了嗎？
我怎麼樣都睡不著。
你先別著急。
# zhuó，順便聽，沒人聽過
